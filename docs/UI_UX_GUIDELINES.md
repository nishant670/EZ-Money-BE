# FINNRI UI/UX Guidelines

## Principles
- Speed: common actions under 3 taps.
- Clarity: numbers are the hero.
- Trust: calm, professional, warm fintech feel.
- Mobile-first: optimize for 320px-428px screens.

## Priority Components
- Voice input button and recording bar
- Confirm transaction bottom sheet
- Transaction card
- Insight card
- Dashboard summary card
- Account selector

## Accessibility
- 44x44 minimum touch target
- WCAG AA contrast
- Screen reader labels
- Support reduced motion
- Support font scaling
- Manual QA follows `docs/ACCESSIBILITY_QA.md`.
