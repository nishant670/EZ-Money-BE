# FINNRI Roadmap

## Phase 0 - Product Cleanup
Finalize MVP scope, repo docs, architecture decisions, backlog boundaries.

## Phase 1 - Habit MVP
Guest onboarding, AI capture, confirmation, accounts, transactions, dashboard, basic insights.

## Phase 2 - Retention
Recurring detection, weekly review, budget alerts, improved insights, optional login/sync.

## Phase 3 - Social/Utilities
Full bill splitting, friend balances, credit card due reminders, EMI tools.

## Phase 4 - Power User/Web
Web dashboard, exports, advanced filters, bulk editing, statement imports.

## Phase 5 - Automation
Bank integrations, Account Aggregator, reconciliation, automated imports.
